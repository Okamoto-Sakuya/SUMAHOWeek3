# Meteor Missile Game

## ゲーム概要

上空から落下してくる隕石を、ロケットから発射するミサイルで破壊する2Dスマホゲームです。
プレイヤーはフリック操作でミサイルを発射し、隕石を破壊してスコアを獲得します。

一定数の隕石を落としてしまうとゲームオーバーになります。


# 使用技術

* Unity
* C#
* UI(Canvas)


# ゲーム仕様

## 隕石

* 画面上部からランダム位置にスポーン
* 一定速度で下へ落下
* ミサイルに当たると破壊される
* 地面に到達するとカウントされる


## プレイヤー

* ロケットからミサイルを発射
* フリック方向へ発射可能
* ミサイルは連射不可
* ミサイル消滅後に再発射可能


## スコア

* 隕石を破壊するとスコア加算
* UI上へ表示


## ゲームオーバー

* 隕石が3回地面へ落下するとGAME OVER


# 主なスクリプト

## MeteorSpawner.cs

隕石のランダム生成を担当。

## Meteor.cs

隕石の移動、衝突判定、スコア処理を担当。

## MissileLauncher.cs

フリック入力によるミサイル発射処理を担当。

## Missile.cs

ミサイルの寿命管理、再発射処理を担当。

## GameManager.cs

スコア管理、ゲームオーバー処理、UI更新を担当。

## SceneLoader.cs

ボタンによるシーン遷移を担当。


# 操作方法

## PC

* フリックで発射方向を決定
* 手を離すとミサイル発射

## スマホ

* フリック方向へミサイル発射
